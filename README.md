# Azulejo — study European Portuguese 🇵🇹

A genuine way to study **Portuguese from Portugal**, for **Dutch speakers**: a course book that explains things properly, a practice section where you write everything yourself, readings that match where you are, tables for every common verb, and spaced-repetition reviews. The only game element is points (and a daily goal). The whole site — explanations, translations, menus — is in Dutch.

- **The course** — 27 chapters from A1 to B1, in a sensible order: sounds and greetings → the grammatical persons (eu, tu, você, o senhor, nós, **what vós is**, vocês, a gente) → how conjugation works → … → the future subjunctive. Each chapter is split into **short parts** (usually 2–4); every part has its explanation, its words and example sentences, and ends with a **short typed test** (about 8 questions, 70% to pass). A chapter is done when all its parts are passed. The explanations include tables you can hear, notes on how Portugal differs from Brazil (and from Dutch), and common mistakes.
- **Oefenen** — writing (translate sentences, write what you hear, fill gaps), conjugation (single forms, whole tables, verbs in sentences) and, from level A1+ on, both mixed together. Choose the chapters, tenses and verbs. Sentences are built from the words you've studied, so they don't repeat; each comes with a Dutch translation.
- **Free writing** — every chapter has writing tasks. On claude.ai, Claude corrects your text and explains each change; elsewhere you compare it with a model answer.
- **Lezen** — 31 texts, at least one for every chapter, using that chapter's grammar. "Para ti agora" suggests the ones for where you are. Tap any word, listen along, answer the questions.
- **Naslag → Grammatica** — a full grammar reference in plain Dutch (26 topics): every grammar word explained, the persons, a complete guide to **vós** (what it is, where you'll meet it, its forms in every tense), how to form and use every tense, and nouns, articles, adjectives, possessives, pronouns, prepositions, questions and numbers. Each chapter links to the topics behind it, and each topic links back to its chapters.
- **Naslag → Werkwoorden** — every tense for 884 verbs, generated by a rule engine with irregular forms and spelling changes highlighted, and vós on its own striped row. The ⓘ on each tense shows the regular pattern and links to its grammar page. Search by any form ("fiz", "tivesse").
- **Reviews** — finishing a chapter adds its words, verbs and tenses to a WaniKani-style review queue (4 hours → 4 months). Every answer is typed.
- **Naslag → Woorden** — 22 themed decks, ~975 words with gender and plurals, and their Dutch with de/het.
- **A real Portuguese voice** — every word, example sentence, reading and core verb form is pre-recorded with a neural European Portuguese voice (see below).

On a phone, the bottom bar has five tabs — **Cursus, Oefenen, Lezen, Naslag, Ik** — and *Naslag* holds the reference pages (words, verbs, grammar). Wide screens show everything in the side menu.

No frameworks and no build step: it is plain HTML, CSS and JavaScript in `public/`.

## Where your progress is saved

| Where Azulejo runs | Saved in |
| --- | --- |
| Opened as a file, or on any plain web host | this browser (localStorage) |
| As an artifact on claude.ai | your private claude.ai storage |
| On Cloudflare (this repo) | a Cloudflare D1 database — with an **account**, on every device |

### Accounts (on your Cloudflare site)

Open **Ik → Account en opslaan** and create an account with a username and password. Whatever you've already done on that device moves into the account. On your phone, laptop or tablet, log in with the same username and your progress is there; if you studied on two devices at once, both are merged.

- **Log out** keeps your progress in the account and gives the device a clean start, so the next person doesn't see it.
- **Change password** logs your other devices out.
- **Delete account** removes the account and its progress for good.
- There's no email, so a forgotten password can't be recovered — keep a backup (Ik → Back-up) if you're worried.
- The password never leaves the browser: it's stretched there (PBKDF2-SHA256, 400,000 rounds) and the Worker stores only a salted hash of the result. Eight wrong passwords lock the account for 15 minutes.

Don't want an account? Every browser also has a private **sync code** (Ik → Account en opslaan → "Geen account? Gebruik een synchronisatiecode"). Type it on another device to continue there.

Moving from the claude.ai version? Use **Ik → Back-up** there to copy a backup, then import it on your own site and paste it in. Progress is merged, so you can do this any time.

## Deploy on Cloudflare

You need a free Cloudflare account.

1. In the Cloudflare dashboard go to **Workers & Pages → Create application → Import a repository**.
2. Connect GitHub and pick your `azulejo` repository.
3. Keep the project name **azulejo** (it must match `name` in `wrangler.jsonc`), leave the build command empty and keep the deploy command `npx wrangler deploy`.
4. Select **Save and Deploy**.

That's it. On the first deploy Wrangler creates the D1 database and connects it to the Worker as `DB`; the tables are created the first time someone saves. Your site is live at `https://azulejo.<your-subdomain>.workers.dev`, and every push to `main` redeploys it. Open **Ik → Account en opslaan** and create your account.

Prefer the command line?

```bash
npm install
npx wrangler login
npm run deploy
```

### If the database was not created

Automatic creation needs Wrangler 4.45 or newer (this repo asks for it). If the deploy log complains about the D1 binding, create the database yourself and paste its id into `wrangler.jsonc`:

```bash
npx wrangler d1 create azulejo
```

```jsonc
"d1_databases": [{ "binding": "DB", "database_name": "azulejo", "database_id": "<the id it printed>" }]
```

Commit, push, done.

### Optional: a sync password

Accounts and sync codes are private, but anyone who finds your site can create their own account on it. If it's just for you (or your family), add a secret so that creating accounts and saving need a password:

```bash
npx wrangler secret put SYNC_TOKEN
```

(or Worker → Settings → Variables and Secrets in the dashboard), then enter the same password in Azulejo under **Ik → Account en opslaan → Geavanceerd** on each device.

### Optional: your own domain

Worker → Settings → Domains & Routes → Add → Custom domain.

## Also on GitHub Pages

The repo publishes itself to **https://dadagames.github.io/Azulejo/** with the workflow in `.github/workflows/pages.yml`, on every push to `main`.

One-time setup: on GitHub, open the repository's **Settings → Pages**, and under *Build and deployment* set **Source** to **GitHub Actions**. Then run the workflow once from the **Actions** tab (*GitHub Pages → Run workflow*), or just push a change.

GitHub Pages only serves files, so the copy there saves through your Cloudflare Worker — its address is in `public/config.js`. Accounts are shared: log in on either address and your progress is the same. (Without an account, each address keeps its own progress in the browser.)

## The voice

Browser voices for Portuguese are often Brazilian or robotic, so Azulejo records its own. The GitHub workflow runs [Piper](https://github.com/OHF-Voice/piper1-gpl) with the European Portuguese voice **tugão** and saves the result in `public/audio/`:

- `audio/c/<key>.mp3` — one file per word, sentence or paragraph (about 4,300)
- `audio/v/<verb>.mp3` + `.json` — every simple-tense form of each of the 211 core verbs in one file, with the start and length of each form
- `audio/index.json` — what has been recorded

`tools/voice-texts.js` lists every Portuguese text on the site and `tools/voice.py` records only what is new and removes what is no longer used; then the workflow commits the audio. So after you edit content, the next push records the new sentences by itself (a full recording from scratch takes about half an hour; an update takes a minute or two). Sentences the generator invents on the fly have no recording; they are silent unless you turn on *Ik → Instellingen → Gebruik de stem van dit apparaat voor zinnen zonder opname*. On claude.ai, where the audio files aren't available, the Claude voice is used instead.

## Visitor counts (Cloudflare Web Analytics)

Azulejo can count visits with Cloudflare Web Analytics, which uses no cookies.

1. In Cloudflare, open **Analytics → Web Analytics**. Use the site for your GitHub Pages address (e.g. `dadagames.github.io`), or **Add a site** for it. Add your Worker's address (`azulejo.<you>.workers.dev`) as a second site if you want that copy counted too, because each token only works on its own address.
2. Click **JS Snippet installation** and copy the token: the long code after `"token": "`.
3. Paste it next to the right address under `analytics` in `public/config.js` and push.

Data appears after a few minutes. The site moves between pages with `#` addresses, which Cloudflare can't follow, so a page view means one opening of the site. Visitors with ad blockers aren't counted. On a shared `github.io` address, filter by the path `/Azulejo/` to see only this site. The claude.ai version and local copies never load analytics.

## How it fits together

```
public/
  index.html          page shell and icons
  config.js           the address of your Cloudflare Worker (used by copies such as GitHub Pages)
  css/app.css         all styling (light and dark)
  js/engine.js        conjugation engine and answer checker (Portuguese and Dutch)
  js/generator.js     builds practice sentences from what you've studied, with a Dutch translation
  js/core.js          progress, chapters and their parts, spaced repetition, points, speech, saving and sync
  js/voice.js         finds and plays the recorded voice
  js/ex.js            typed exercises, the practice player, the test after each part, Claude corrections
  js/ui.js            screens: course, chapter pages, practice, reading, verbs, words, profile
  data/book.js        the course book, part 1: chapter order, explanations, goals, writing tasks (A1)
  data/book2.js       the course book, part 2 (A2–B1)
  data/grammar.js     the grammar reference: topic groups, chapter ↔ topic links, and the first topics
  data/grammar2.js    the grammar reference, continued
  data/course-a1.js, course-a2b1.js   each chapter's vocabulary and example sentences
  data/readings.js, readings2.js      graded texts
  data/verbs.js       884 verbs (* = core)
  data/vocab.js       22 vocabulary decks
  data/gen.js         word classes, sentence frames and Dutch verbs and plurals for the generator
  audio/              the recorded voice (made by the workflow)
worker/index.js       Cloudflare Worker: /api/health, /api/progress/<code> and /api/account/*
wrangler.jsonc        Cloudflare configuration
.github/workflows/    records the voice and publishes public/ to GitHub Pages
tools/                voice-texts.js (every Portuguese text) and voice.py (records them with Piper)
tests/                content and engine checks
```

The Worker only handles `/api/*`; everything else is served straight from `public/`. Each save carries the version it builds on, so a device that is out of date gets the newer progress back, merges it and saves again.

## Editing the content

Everything you'd want to change lives in `public/data/` as plain text:

- **Chapters** (`book.js`, `book2.js`): the order of chapters in `levels`, the readings for each chapter in `reads`, and for each chapter its `goals`, its explanation `text` and its free-writing tasks `write`. The explanation uses a tiny markup:
  - `@deel Title {1,2}` starts a part; the numbers are the lessons (from `course-*.js`) whose words and sentences belong to it. Every lesson must be in exactly one part.
  - `## Heading`, `### Subheading`, plain lines for paragraphs, `- ` for bullets
  - `> Portuguese = Dutch` for an example with a play button
  - `!tip …`, `!pt …` (a note about Portugal), `!warn …` (a common mistake)
  - `|! header | cells |` and `| cell | cell |` for tables
  - `@conj falar,comer,partir pres` for a live conjugation table (tense keys: pres, pret, imp, mqp, fut, cond, cpres, cimp, cfut, impa, impn, infp)
  - `[[vos]]` or `[[vos|any text]]` for a link to a grammar topic, `[[u17]]` for a link to a chapter, and `@see vos persons` for a row of links
- **Grammar** (`grammar.js`, `grammar2.js`): `groups` lists the topics in order, `chapters` says which topics go with each chapter, `tenses` gives the topic for each tense, and `t` holds the topics, written in the same markup.
- **Vocabulary and examples per chapter** (`course-*.js`): lessons are `Title|word, word, v:verb`; sentences are `lesson: Portuguese / alternative | Dutch / alternative`, with `{braces}` around a word to make it a gap.
- **Verbs** (`verbs.js`): one per line, `infinitive|Dutch`, `*` in front for a core verb. The engine conjugates it; truly irregular verbs get their forms in `js/engine.js`.
- **Words** (`vocab.js`): `portuguese|dutch (nouns with de/het)|type|picture|extras`, where type is `m`, `f`, `mf`, `adj`, `adv`… and extras are things like `pl=irmãos` or `f=irmã`.
- **Readings** (`readings*.js`): paragraphs separated by a blank line, one translation per paragraph, multiple-choice questions with the index of the right answer.

After editing, run the checks:

```bash
npm test
```
